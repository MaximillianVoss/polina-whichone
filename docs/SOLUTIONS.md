# WhichOne: подробные решения

1. Папка проекта содержит pom.xml и Maven Wrapper. Запуск: bash ./scripts/build-and-run.sh; главная страница http://localhost:8080/. В AuthService.register пароль передаётся в passwords.encode; TokenService.issue подписывает JWT. SecurityConfig.jwtDecoder проверяет подпись, issuer, audience и срок. QuizService.create вызывает auth.requireUser(username), где username пришёл из @AuthenticationPrincipal Jwt в controller, затем new Quiz(user) устанавливает автора.
2. Первый вопрос даёт3 балла, второй2. Выбранные 4 и table дают3 +0 =3 балла из5, процент3/5 ×100 =60. ScoringService.educational суммирует points только у правильных выборов. AttemptService.submit получает варианты из БД и сохраняет score=3, maxScore=5. При одной учебной попытке averagePercent=60, bestPercent=60.
3. Выбор «Составляю план» и «Через эксперименты» даёт по2 каждому исходу. PLANNER первым записан в outcomes и выигрывает равенство. В ScoringService.personality победитель первоначально первый; замена выполняется только при строго большей сумме. При тесте ZEBRA/ALPHA это правило также выбирает ZEBRA, показывая независимость от алфавита.
4. Вход второго пользователя сам по себе не даёт ему владение. QuizService.ownedLocked сравнивает quiz.author.username с subject токена. PUT, POST publish и DELETE чужого существующего квиза дают403. Чтение чужого черновика даёт404. Изменение собственного опубликованного квиза даёт409, потому что данные результата должны оставаться стабильными.
5. OptionView содержит только id и text. Исходы личностного квиза доступны как code/label/description, но связь вариантов с исходами и веса скрыты. AttemptService.validatedOptions находит optionId только внутри options именно текущего questionId. Вариант другого вопроса или другого квиза не находится:400. Сохранение попытки не выполняется.
6. До учебной попытки totalAttempts=0, averagePercent=null, bestPercent=null. После результатов3/5 и5/5 проценты60 и100, среднее(60+100)/2 =80, максимум100. Личностная попытка увеличивает счётчики, но не меняет учебный процент. Каждый outcome группируется с quizId; одинаковые коды в разных квизах не смешиваются.
