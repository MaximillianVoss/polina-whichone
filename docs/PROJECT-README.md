# WhichOne — итоговый Backend проект

Готовое независимое приложение Spring Boot: регистрация и вход с JWT, создание своих квизов, публикация, прохождение двух типов, серверные результаты и собственная статистика. Есть браузерная демонстрация и интерактивная документация OpenAPI.

## Быстрый запуск на Mac

Скопируй эту папку как отдельный проект, например в <локальный-путь> Нужен JDK 17 или 21; Maven устанавливать отдельно не требуется.

~~~bash
cd <папка-этого-репозитория>
java -version
bash ./scripts/build-and-run.sh
~~~

Открой http://localhost:8080/. Зарегистрируйся, нажми «Создать два примера», пройди квиз и нажми «Статистика». Остановить приложение: Ctrl+C в терминале запуска.

Если порт занят:

~~~bash
PORT=8085 bash ./scripts/build-and-run.sh
~~~

На Windows: открой PowerShell в папке проекта и выполни:

~~~powershell
.\scripts\build-and-run.ps1
~~~

Первый запуск скачивает зависимости. По умолчанию используется файловая H2: база появится в data/. Приложение доступно только на локальной машине. Тесты используют отдельную H2 в памяти и не затрагивают данные демонстрации.
