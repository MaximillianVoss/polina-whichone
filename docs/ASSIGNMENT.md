# Backend Final: требования

Источник — предоставленный sources/final_tasks.pdf, страницы 2–3 общего учебного комплекта; ниже требования в русском изложении. Полный оригинальный PDF остаётся в общем комплекте.

1. Создать новый Spring Boot проект через Spring Initializr. Не копировать и не переименовывать Bookstore.
2. Написать достаточно объёмное приложение, соблюсти срок, объяснять собственный код.
3. Структурировать пакеты, комментировать существенные решения.
4. Подключить базу данных и написать тесты.
5. Для расширенного варианта использовать аутентификацию и GitHub.
6. На оценку 5 в PDF указаны PostgreSQL либо MariaDB, самостоятельно изученные возможности Spring Boot и развёртывание на сервере в интернете. RESTful service указан как optional.

| Оценка из PDF | Требования |
|---|---|
| 1 | Достаточный объём и сдача в срок |
| 2 | Объём, срок, БД (H2 допустима), простые тесты |
| 3–4 | Более широкий объём, срок, аутентификация, БД, структурированный и прокомментированный код, несколько тестов, GitHub |
| 5 | Широкий объём, срок, дополнительные самостоятельно изученные возможности, аутентификация, PostgreSQL/MariaDB, структурированный и прокомментированный код, GitHub, сервер в интернете; REST optional |

Тема WhichOne: пользователи создают и проходят обучающие и личностные викторины; есть лента и статистика. Предложенный стек: Spring Boot, PostgreSQL, Spring Security + JWT, Spring Data JPA, Swagger / OpenAPI, Docker.

JWT, Swagger и Docker относятся к предложению проекта, а не к обязательным пунктам общей шкалы. В предоставленных материалах нет подтверждения утверждения темы, точного срока, требований преподавателя к дополнительной технологии или гарантированной оценки.

## Реализованное решение

- Обычная регистрация, BCrypt парольные хеши, вход с JWT.
- Автор создаёт, заменяет и удаляет свой черновик. После публикации квиз неизменяем.
- Общедоступная лента и тексты опубликованных квизов.
- По одному варианту на каждый вопрос; расчёт и проверка принадлежности вариантов на сервере.
- Обучающие квизы: сумма баллов за правильные ответы.
- Личностные квизы: сумма весов по исходам; при равенстве выигрывает первый исход из авторского списка.
- Собственные результаты и статистика.
- DTO без скрытых ключей ответов, весов и парольных хешей в чтении квизов.
- Файловая H2 для простого запуска, PostgreSQL профиль и Flyway миграция.
- Интерактивный OpenAPI, страница демонстрации, Dockerfile и локальный Compose.

Неопределённые условия закрыты этими явно описанными решениями. Они не выданы за дополнительные требования преподавателя. GitHub, интернет-сервер, срок и согласование темы остаются действиями при сдаче; внешние ресурсы этот комплект не создаёт.
