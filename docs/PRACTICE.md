# WhichOne: задания без ответов

1. Запусти проект на H2, зарегистрируй пользователя и создай два примера. Найди в исходниках, где сервер берёт автора и проверяет JWT.
2. Пройди обучающий пример так, чтобы первый ответ был правильным, а второй неправильным. До отправки самостоятельно вычисли баллы и процент. Сравни с сохранённой статистикой.
3. В личностном примере выбери один ответ планировщика и один ответ исследователя. Объясни правило разрешения равенства и найди реализующий его переход.
4. Создай черновик. Создай второй аккаунт и попытайся изменить, опубликовать и удалить чужой черновик через OpenAPI. Запиши HTTP статусы.
5. Получи опубликованный квиз через GET. Найди, какие сведения присутствуют в вариантах и каких нет. Затем отправь optionId от другого вопроса. Объясни, какая серверная проверка должна сработать.
6. Получи статистику нового пользователя до учебной попытки. Затем пройди один квиз дважды с различными результатами. Объясни, что означает среднее и почему это не средний сырой score.

Решения находятся в отдельном SOLUTIONS.md. Для выполнения нужен собственный локальный проект; выполнять внешнее развёртывание или менять чужие проекты не требуется.
