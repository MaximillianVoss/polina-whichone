# WhichOne: фактическая проверка

Дата: 2026-10-05. Среда: Windows PowerShell, Java 21.0.2, Maven Wrapper 3.9.16, Spring Boot 3.5.16. Исходники компилируются с release 17.

## Выполнено

- Получен новый каркас Spring Initializr. Генератор сейчас поддерживает Boot >=4.0; каркас 4.0.8 адаптирован на 3.5.16, без бизнес-кода Bookstore.
- Тесты написаны до реализации; первый прогон дал ожидаемую ошибку отсутствующих классов.
- Свежий mvnw.cmd -B clean verify: BUILD SUCCESS, 27 тестов, 0 failures, 0 errors, 0 skipped.
- 5 unit тестов: точные учебные баллы, личностный максимум, равенство, нулевые веса, неизвестный исход.
- 22 интеграционных теста с H2, Flyway, настоящими HTTP регистрацией/входом и JWT: BCrypt, дубликаты, неправильный пароль, защищённые endpoints, чужое изменение, скрытые черновики, immutable publication, изменение/удаление своего черновика, foreign option, неполные/дублированные ответы, score, personality tie, собственная история и статистика, DTO leakage, валидация, запрет неизвестных полей и назначения автора/роли, подпись/expiry/issuer/audience JWT, повторная миграция, OpenAPI и статика.
- Собранный JAR запущен отдельно на http://127.0.0.1:8187/ с новой файловой H2. Корневая страница действительно отрисована в Chrome, не только проверена внутренним MockMvc forward.
- Через UI выполнены регистрация, создание и публикация обоих примеров, образовательный результат 3/5 и статистика 60%, личностное равенство -> PLANNER; итог 2 попытки, 1 educational, 1 personality.
- Проверены виды 1280×900 и 390×844; на узком окне scrollWidth=390 при innerWidth=390, горизонтального переполнения нет.
- Снимки desktop/mobile просмотрены. В браузере console: 0 errors, 0 warnings. localStorage и sessionStorage пусты; JWT остаётся только в памяти страницы.
- Flyway повторно не применяет V1 в тестовой H2 и сохраняет пользователя.
- Независимая проверка выявила сохранение частного черновика в интерфейсе после смены аккаунта. Исправлены очистка private DOM/currentQuiz/JSON определения и authEpoch для запоздалых ответов и цепочек запросов.
- scripts/ui-regression.cjs: тест сначала воспроизвёл старый currentQuiz Alice после выхода (RED), затем 5/5 PASS. Проверяются выход и прямое переключение Alice -> Bob, запоздалый private feed200, запоздалый401 без выхода Bob и запоздалый private quiz. Это Node VM с минимальным DOM, исполняющий настоящий app.js; после исправления отдельный браузерный прогон не повторялся.

Снимки и промежуточные браузерные отчёты находятся в output/playwright/ рабочей папки; временные отчёты и базы не нужны для сдачи исходников.

## Что не подтверждено этой средой

После подтверждённой clean verify в 15:33 главная задача поправила очистку статуса app.js и null Target в Windows Wrapper (Java-код не менялся). Итоговый app.js проверен 5/5 regression, два мануала точно совпадают с 48 файлами. Исправленный mvnw.cmd -v успешно запускает Maven 3.9.16. Последняя повторная clean verify не дошла до тестов: сеть Maven Central ограничена sandbox, а автоматическое согласование расширенного доступа не смогло выполниться из-за загрузки модели. Поэтому полная пересборка после этих последних правок не объявляется подтверждённой.

- Запуск на настоящем Mac ученицы и на Java 17 отдельно: выполнялась Java 21 с release 17.
- PostgreSQL runtime и сборка/запуск Docker image: Docker daemon не работает (pipe docker_engine отсутствует). Профиль, миграция и Compose подготовлены; команды повторной проверки приведены в MANUAL.
- Интернет-развёртывание, внешний HTTPS, GitHub и утверждение темы преподавателем.
- Нагрузочное тестирование и боевые меры против перебора паролей.

Проверенный локальный проект не является доказательством интернет-развёртывания и не гарантирует оценку 5.
